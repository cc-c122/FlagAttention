# C550：适配原版与最终版的完整性能表

**适配原版 = V0**：最初已完成 C550 正确性适配的版本；**最终版 = V5**：完成后续优化及 shape 泛化的版本。两列耗时单位均为毫秒（ms），**加速比 = 适配原版耗时 ÷ 最终版耗时**，每行比较相同的输入配置。Query 头数、KV 头数和每头维度分别对应 Hq、Hkv 和 D；Q、KV 长度均指每条序列的 token 数。

230 组前向均可直接比较，等权几何平均加速 **6.92×**，230 组加速比均超过 1.05。另测 18 组前向加反向，其中 6 组可比较，12 组适配原版无法运行；这 12 组单列最终版耗时，不计算加速比。

按计算阶段、精度和场景分组。各组共同参数列在表格上方，变化参数各占一列。“无法运行”表示 V0 执行失败，“—”表示不计算加速比。原始错误及每组 11 轮样本保存在 [comparison_results.json](comparison_results.json)。

`Block` 为每块 token 数，`TopK` 为选块数量，初始块/局部块为窗口参数；`dense_len` 为 dense 分派阈值（KV 长度小于它时走 dense）。Dense 路径不消费选块参数。压缩配置均为 K1 kernel/stride=32/16、K2 kernel/stride=128/64。
